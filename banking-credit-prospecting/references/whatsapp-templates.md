# Template WhatsApp Personal

Gunakan hanya jika consent WhatsApp diverifikasi. Sesuaikan dengan konteks sebenarnya; jangan menyebut pernah bertanya jika belum.

## Cold dengan izin
"Halo Pak/Bu [Nama], saya [Officer] dari [Bank]. Saya menghubungi karena Bapak/Ibu sudah mendaftar untuk menerima informasi pembiayaan lewat [sumber nyata]. Kalau sedang mempertimbangkan tambahan modal usaha, boleh saya kirim ringkasan pilihan dan persyaratannya?"

## Warm KPR
"Selamat siang Bu [Nama], saya [Officer] dari [Bank]. Saya menindaklanjuti pertanyaan KPR Ibu melalui [kanal nyata]. Ibu sudah ada rumah incaran atau masih melihat-lihat, ya? Nanti saya bantu jelaskan opsi dan gambaran cicilannya."

## Warm modal kerja
"Halo Pak [Nama], kemarin Bapak sempat menanyakan tambahan modal untuk usaha. Boleh saya tahu kebutuhan utamanya untuk stok barang atau pengembangan? Supaya informasinya tidak terlalu umum."

## Existing dengan consent
"Halo Pak [Nama], saya [Officer] dari [Bank]. Kalau ada rencana pembiayaan baru untuk usaha, saya bisa bantu jelaskan pilihan dan persyaratannya. Saat ini ada kebutuhan yang sedang Bapak pertimbangkan?"

## Follow-up kontekstual
"Halo Pak, saya ingin menindaklanjuti soal pembiayaan yang kemarin sempat dibahas. Kalau masih relevan, saya bisa bantu siapkan gambaran cicilan dan biayanya. Perlu saya bantu, Pak?"

## Closing the loop
"Baik Pak, saya tidak akan menindaklanjuti penawaran ini lagi. Terima kasih waktunya. Jika nanti membutuhkan informasi, silakan hubungi [kontak resmi]."

Jangan otomatis menjadwalkan broadcast. Satu pertanyaan dalam satu pesan. Jika ditolak, berhenti. Jangan mencantumkan rincian rekening atau data sensitif.
