# Segmentasi & Conversation Journey

Segmentasi hubungan: cold (belum ada interaksi relevan), warm (sudah bertanya/isi formulir/minta simulasi), existing (nasabah aktif). Pisahkan dari intent: unknown, interested, high intent. Periksa consent setiap kanal secara independen.

Cold berizin: tujuan interest/reply, identitas+alasan kontak+relevansi+pertanyaan ringan, jangan langsung minta aplikasi.
Warm: rujuk interaksi yang benar-benar terjadi, tanyakan satu kebutuhan dan tawarkan simulasi setelah cukup informasi.
Existing: jangan menganggap relasi sebagai izin marketing; tanyakan kebutuhan baru tanpa menyebut data rekening, penghasilan atau perilaku transaksi pribadi.

Tahapan CRM: consent verified → contacted → engaged → need discovery → qualified → consultation/simulation → application → approved/rejected → disbursed/closed. Kredit disetujui menurut keputusan bank.

SPIN: Situation (kondisi), Problem (kendala), Implication (dampak), Need-Payoff (nilai solusi). Ajukan satu per satu sesuai respons, bukan kuisioner sekaligus.

NBA: jika meminta simulasi → simulasi resmi; jika ragu bunga → klarifikasi total biaya; jika ingin mengajukan → jelaskan proses resmi; jika menolak → stop.
